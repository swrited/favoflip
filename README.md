# FavoFlip (Web Favorites Clipper)

FavoFlip 是一个简洁的 Chrome 浏览器扩展，可以帮助你轻松收集网页上的文字和图片到本地收藏夹。

## ✨ 功能特点

*   **右键收藏**：选中网页上的任何文字或图片，右键菜单一键添加到收藏。
*   **本地存储**：数据安全地存储在你的本地浏览器中，无需注册账号。
*   **简洁管理**：通过弹出式窗口轻松查看和管理你的收藏内容。
*   **一键清理**：支持删除单个条目或清空所有收藏。

## 🚀 安装指南

1.  克隆或下载本项目到本地。
2.  打开 Chrome 浏览器，访问 `chrome://extensions/`。
3.  开启右上角的 **"开发者模式" (Developer mode)**。
4.  点击左上角的 **"加载已解压的扩展程序" (Load unpacked)**。
5.  选择本项目所在的文件夹即可。

## 📖 使用方法

1.  **收藏内容**：
    *   **文字**：鼠标选中一段文字，点击右键，选择 "Add to Favorites"。
    *   **图片**：在图片上点击右键，选择 "Add to Favorites"。
    *   **链接**：在链接上点击右键，选择 "Add to Favorites"。
2.  **查看收藏**：
    *   点击浏览器常用工具栏中的 FavoFlip 图标（如果没有显示，请在拼图图标里找到并固定）。
    *   在弹出的窗口中可以看到你收藏的所有内容。

## 🛠️ 开发

本项目使用原生 HTML/CSS/JavaScript 构建，无需复杂的构建流程。

*   `manifest.json`: 扩展程序的配置文件。
*   `background.js`: 处理右键菜单事件的后台脚本。
*   `popup/`: 包含弹窗的界面和逻辑代码。
